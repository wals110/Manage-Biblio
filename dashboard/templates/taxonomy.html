    Thèmes LLM

    categories.yaml est l'étape 2 du pipeline de classification. C'est un filet de sécurité quand l'étape 1 (theme_mapping.yaml) ne résout pas le thème détecté par le LLM.

    1. theme_mapping → 2. categories ← ici → 3. LLM Mapper ($) → 4. _A-TRIER
    • Groupe (informatique, mathematique…) — clé top-level du YAML, sert juste à regrouper
    • Entry — un chemin cible (dossier de destination) avec une priorité et une liste de mots-clés
    • Priorité — plus le nombre est bas, plus l'entry gagne quand plusieurs matchent (P1 bat P2)
    • Mot-clé — substring cherché dans le titre + filename + thème du fichier (insensible à la casse)

    Exemple : un fichier Hands-On GAN for Image Synthesis.pdf dont le thème LLM n'est pas mappé à l'étape 1 sera attrapé ici via le mot-clé GAN et classé dans 05-IA-ML/Deep-Learning.
